# VIO Group

VIO Group is a fictional multinational tour operator, built to show how architecture knowledge spread across
teams, notations and tools becomes one knowledge graph. This is that graph: the group's ArchiMate model, the
booking domain in C4, three business processes in BPMN, a LeanIX portfolio, architecture decision records and
the Backstage catalog of the delivery teams' systems, each converted to RDF, their identities reconciled, and
joined.

| | |
| --- | --- |
| RDF | `vio.trig` |
| ArchiMate model | `vio.xml`, in the ArchiMate Exchange Format: the file the graph's ArchiMate part was converted from. `vio.archimate`, the same model as an Archi model. Both were exported by Archi 5.7.0 from the coArchi repository, in the same run |
| Languages | ArchiMate 3.2, C4, BPMN 2.0, LeanIX, Backstage, architecture decision records |
| Base IRI | `https://linked.archi/examples/vio/` |
| Made from | The sources and the pipeline that joins them, in [linked-archi/examples/vio](https://gitlab.com/linked-archi/examples/vio) on GitLab: an Archi (coArchi) model, a Structurizr C4 workspace, BPMN 2.0 processes, a LeanIX export, decision records and Backstage catalog descriptors |
| State | The workshop's starter state, before its exercises are solved |
